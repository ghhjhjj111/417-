一、多商户模块
商户入驻：资质审核、店铺装修、分类管理

商品管理：SPU/SKU、规格、库存、沽清、上下架

订单分流：按商户拆单，独立接单、出餐、退款

资金合规：平台代收必须走微信/支付宝分账，否则二清违法

抽佣结算：按商户/品类/活动配置佣金比例，T+1/T+7 结算

二、骑手调度模块
骑手端：接单、抢单、导航、取餐、送达、异常上报

调度策略：就近派单、批量派单、超时转单、手动改派

LBS 定位：实时位置上报、围栏、轨迹回放

运力管理：骑手入驻、保证金、排班、考核

配送费计算：距离 + 重量 + 时段 + 天气动态定价

三、智能订单模块
订单状态机：待支付→已支付→商户接单→出餐→骑手取餐→配送中→已完成/已取消

智能拆单：跨商户订单自动拆分，分别结算

超时预警：出餐超时、配送超时自动提醒/转单

退款售后：部分退款、整单退款、原路退回 + 分账回退

异常处理：拒单、取消、丢餐、投诉
